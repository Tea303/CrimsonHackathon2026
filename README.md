# CrimsonHackathon2026 - Cooking AI App

This project is a Flask-based web application that parses recipes from URLs using web scraping and Google Gemini AI. It also provides AI-generated answers to questions about the recipes and generates audio responses using ElevenLabs.

## Prerequisites

- Python 3.8 or higher
- A Google Gemini API Key
- An ElevenLabs API Key and Voice ID

## Setup Instructions

### 1. Clone the Repository

```bash
git clone <repository-url>
cd CrimsonHackathon2026
```

### 2. Navigate to the App Directory

The application code resides in the `cooking ai app` folder.

```bash
cd "cooking ai app"
```

### 3. Create and Activate a Virtual Environment

**Windows (PowerShell):**
```powershell
python -m venv .venv
& .venv\Scripts\Activate.ps1
```

**macOS/Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Application

```bash
python app.py
```
